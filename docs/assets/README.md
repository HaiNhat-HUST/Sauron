# Media assets for the project README

Drop the screenshots and the demo video here, using the exact filenames the
top-level `README.md` references:

| File | What to capture |
|------|-----------------|
| `demo-thumbnail.png` | A still frame / cover image for the demo video |
| `demo.mp4` | Full walkthrough (collection → enrichment → graph → chat) |
| `dashboard.png` | The Overview / dashboard page |
| `graph.png` | An article opened with its relationship graph expanded |
| `chat.png` | The Intel chat agent answering a question |
| `admin.png` | The admin console (connectors or LLM models) |
| `graph-filter.png` | The graph with the entity-type filter in use |
| `enrichment.png` | A node tooltip showing CVE/EPSS or hash intel |

Tips:
- Use PNG for screenshots; keep them under ~1 MB each (crop to the content).
- For the demo, GitHub also renders an `.mp4` inline if you upload it by dragging
  it into a comment box and pasting the resulting URL into the README — handy if
  you'd rather not commit a large binary to the repo.
